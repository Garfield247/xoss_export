# 🚴 行者数据导出工具

一个用于从行者网站导出 GPX 运动数据的 Python 工具，支持按运动类型、年份、月份等条件筛选导出。

提供两种使用方式：
- **命令行版本** (`xoss_export.py`) - 适合批量处理和自动化
- **图形界面版本** (`xoss_export_gui.py`) - 适合普通用户使用

## ✨ 功能特性

- 🎯 **精确筛选**: 支持按运动类型、年份、月份筛选数据
- 📊 **批量导出**: 可自定义每次请求的记录数量
- 🎨 **美观界面**: 彩色控制台输出，专业 tqdm 进度条
- 📁 **自动管理**: 使用 pathlib 自动创建导出目录
- 🔧 **灵活配置**: 丰富的命令行参数选项
- ⚡ **高效下载**: 支持断点续传和错误重试

## 🚀 快速开始

### 环境要求

- Python 3.8+
- requests 库
- tqdm 库
- PyQt5 库（GUI版本需要）

### 安装依赖

```bash
pip install -r requirements.txt
```

或者单独安装：

```bash
# 命令行版本
pip install requests tqdm

# GUI版本（包含命令行版本的所有依赖）
pip install requests tqdm PyQt5
```

### 基本使用

#### 命令行版本

```bash
# 导出所有数据
python xoss_export.py --cookies "your_cookies_here"

# 导出到指定目录
python xoss_export.py -c "your_cookies_here" -o "my_exports"
```

#### GUI版本

```bash
# 启动图形界面
python xoss_export_gui.py
```

GUI版本提供友好的图形界面，无需记忆命令行参数，适合普通用户使用。

## 🖥️ GUI版本使用指南

### 界面介绍

GUI版本提供直观的图形界面，包含以下主要区域：

1. **认证信息区域**
   - Cookie输入框：粘贴从浏览器复制的完整Cookie字符串（自动去除换行符）

2. **导出设置区域**
   - 输出目录：选择GPX文件的保存位置
   - 每次请求数量：下拉选择（10、20、50、100）

3. **筛选条件区域**
   - 运动类型：下拉选择要导出的运动类型
   - 年份：输入要筛选的年份（如：2024）
   - 月份：下拉选择月份（1-12，或全部）

4. **控制按钮**
   - 🚀 开始导出：启动数据导出过程
   - ⏹️ 停止导出：中断正在进行的导出

5. **导出日志区域**
   - 实时显示导出进度和状态信息
   - 显示详细的下载日志
   - 进度条位于日志下方，显示当前下载进度

### 使用步骤

1. **获取Cookie**
   - 按照下方"获取Cookie"说明获取完整的Cookie字符串
   - 将Cookie粘贴到"认证信息"区域的文本框中

2. **配置导出设置**
   - 选择输出目录（默认为"export_file"）
   - 设置每次请求数量（建议10-50之间）

3. **设置筛选条件**
   - 选择运动类型（默认"全部"）
   - 输入年份（可选）
   - 选择月份（默认"全部"）

4. **开始导出**
   - 点击"🚀 开始导出"按钮
   - 在日志区域查看导出进度
   - 导出完成后会显示成功提示

## 📖 详细使用说明

### 获取 Cookie

1. 打开浏览器，访问 [行者网站](https://www.imxingzhe.com)
2. 登录您的账户
3. 按 F12 打开开发者工具
4. 切换到 Network 标签页
5. 刷新页面或进行任何操作
6. 在请求头中找到 `Cookie` 字段
7. 复制完整的 Cookie 字符串

**⚠️ 重要提示**: Cookie 中必须包含 `sessionid` 字段，这是程序正常运行的必要条件。如果 Cookie 中缺少 sessionid，程序会提示错误并退出。

### 命令行参数

| 参数 | 短参数 | 类型 | 默认值 | 说明 |
|------|--------|------|--------|------|
| `--cookies` | `-c` | 字符串 | 必需 | 浏览器中的 Cookie 字符串 |
| `--output-dir` | `-o` | 字符串 | `export_file` | 导出文件的保存目录 |
| `--limit` | `-l` | 整数 | `10` | 每次请求的记录数量 |
| `--sport` | `-s` | 选择项 | 空 | 运动类型筛选 |
| `--year` | `-y` | 字符串 | 空 | 年份筛选 |
| `--month` | `-m` | 字符串 | 空 | 月份筛选 |

### 运动类型选项

支持数字格式和中文格式：

| 中文名称 | 数字代码 | 说明 |
|---------|---------|------|
| 其他 | 0 | 其他运动类型 |
| 徒步 | 1 | 徒步运动 |
| 跑步 | 2 | 跑步运动 |
| 骑行 | 3 | 骑行运动 |
| 游泳 | 4 | 游泳运动 |
| 滑雪 | 5 | 滑雪运动 |
| 训练 | 6 | 训练运动 |
| 室内骑行 | 7 | 室内骑行 |
| 虚拟骑行 | 8 | 虚拟骑行 |

## 💡 使用示例

### 基本导出

```bash
# 导出所有运动数据
python xoss_export.py --cookies "Hm_lvt_34511ef7a75613f0a6c610ac70013063=1757660504; HMACCOUNT=DF3A4D4E11645C0D; ..."
```

### 按运动类型筛选

```bash
# 只导出跑步数据（中文格式）
python xoss_export.py -c "your_cookies" -s "跑步"

# 只导出骑行数据（数字格式）
python xoss_export.py -c "your_cookies" -s "3"
```

### 按时间筛选

```bash
# 导出2024年的数据
python xoss_export.py -c "your_cookies" -y "2024"

# 导出2024年1月的数据
python xoss_export.py -c "your_cookies" -y "2024" -m "01"

# 导出2024年1月的跑步数据
python xoss_export.py -c "your_cookies" -s "跑步" -y "2024" -m "01"
```

### 调整请求参数

```bash
# 每次请求50条记录（提高效率）
python xoss_export.py -c "your_cookies" -l 50

# 每次请求5条记录（降低服务器压力）
python xoss_export.py -c "your_cookies" -l 5
```

### 组合使用

```bash
# 导出2024年所有骑行数据到指定目录，每次请求20条
python xoss_export.py -c "your_cookies" -o "cycling_2024" -s "骑行" -y "2024" -l 20
```

## ⚠️ 注意事项

1. **Cookie 有效期**: Cookie 会过期，需要定期更新
2. **请求频率**: 程序内置了1秒延迟，避免对服务器造成压力
3. **网络连接**: 确保网络连接稳定，避免下载中断
4. **存储空间**: 确保有足够的磁盘空间存储 GPX 文件

## 🐛 常见问题

### Q: Cookie 无效怎么办？
A: 重新登录行者网站，获取新的 Cookie 字符串。确保 Cookie 中包含 `sessionid` 字段。

### Q: 提示"Cookie中必须包含sessionid"怎么办？
A: 这表示您复制的 Cookie 不完整。请重新获取 Cookie，确保包含完整的 `sessionid=xxx` 字段。通常 sessionid 是登录状态的关键标识。

### Q: 下载失败怎么办？
A: 检查网络连接，确保 Cookie 有效，可以尝试降低 `--limit` 参数值。

### Q: 如何只下载特定日期的数据？
A: 使用 `--year` 和 `--month` 参数进行时间筛选。

### Q: 程序运行很慢怎么办？
A: 可以适当增加 `--limit` 参数值，但不要设置过大以免被服务器限制。

### Q: 进度条显示什么信息？
A: 使用 tqdm 库的专业进度条，显示当前页面的下载进度、下载速度、剩余时间、当前文件名等信息。页面完成后会显示总体进度。
