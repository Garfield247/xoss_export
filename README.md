# 🚴 行者数据导出工具

一个用于从行者网站导出 GPX/FIT 运动数据的工具，支持按运动类型、年份、月份等条件筛选导出。

提供两种使用方式：

- **图形界面版本** (`xoss_export_gui.py`) - **推荐方式**，支持扫码登录，简单直观
- **命令行版本** (`xoss_export.py`) - 适合技术用户、批量处理和自动化

## ✨ 主要功能

- 🔐 **自动登录**: 内嵌浏览器支持账号密码或扫码登录，告别手动复制 Cookie。
- 📦 **多格式支持**: 支持导出 `GPX` (基础数据) 和 `FIT` (包含原始传感器数据) 格式。
- 📂 **智能分类**: 每次导出自动创建带时间戳的文件夹，防止数据混乱。
- 🏃 **多维筛选**: 支持按运动类型（骑行、跑步等）、年份、月份精确筛选。
- 💾 **状态保持**: 记住登录状态和上次导出的路径，下次启动即用。

## 🚀 快速开始 (使用 UV)

本工具推荐使用 [uv](https://github.com/astral-sh/uv) 进行环境管理，更加快速、可靠。

### 1. 安装依赖

```bash
# 同步并安装所有依赖
uv sync
```

### 2. 启动工具

#### 推荐方式：GUI 版本

```bash
uv run python xoss_export_gui.py
```

#### 进阶方式：命令行版本

```bash
# 导出 FIT 格式数据到指定目录
uv run python xoss_export.py --cookies "your_sessionid_cookie" --format fit -o "my_exports"
```

## 🖥️ GUI 版本使用指南

### 使用步骤

1. **登录**: 点击“登录账号”按钮，在弹出的窗口中扫码或输入账号登录行者。
2. **设置路径**: 默认保存到桌面，可点击“浏览”修改，软件会记住你的选择。
3. **选择格式**: 勾选 “GPX” 或 “FIT”。
4. **筛选条件**: 根据需要选择运动类型或特定年份/月份。
5. **开始**: 点击“🚀 开始导出”，在下方日志区查看实时进度。

### 退出登录
如需切换账号，点击“退出登录”按钮即可清除所有本地保存的身份信息。

## 📖 命令行详细说明

| 参数           | 短参数 | 类型   | 默认值        | 说明                     |
| -------------- | ------ | ------ | ------------- | ------------------------ |
| `--cookies`    | `-c`   | 字符串 | 必需          | 包含 sessionid 的 Cookie 字符串 |
| `--format`     | `-f`   | 选择项 | `gpx`         | 导出格式：`gpx` 或 `fit`   |
| `--output-dir` | `-o`   | 字符串 | `export_file` | 导出文件保存的基础目录     |
| `--sport`      | `-s`   | 选择项 | 全部          | 运动类型筛选             |
| `--year`       | `-y`   | 字符串 | 不限          | 年份筛选 (如 2024)       |
| `--month`      | `-m`   | 字符串 | 全部          | 月份筛选 (1-12)          |

### 运动类型参考
`0:其他`, `1:徒步`, `2:跑步`, `3:骑行`, `4:游泳`, `5:滑雪`, `6:训练`, `7:室内骑行`, `8:虚拟骑行`
